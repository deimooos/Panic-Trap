# Panic-Trap: Zero-Trust Continuous Authentication Agent

## 🇬🇧 Project Overview
The objective of this project is to develop an autonomous endpoint security agent that provides continuous authentication and active cyber defense based on a user's typing behavior. Adopting a "Zero Trust" architecture, the system relies on n-gram behavioral biometrics to detect unauthorized physical access. It mitigates potential data exfiltration through a 3-tiered incident response mechanism: silent reconnaissance, a tamper-proof honeypot 2FA screen with Telegram API alerts, and a "Nuclear Option" (network isolation and OS hard-lock).

## 🇹🇷 Proje Özeti
Bu projenin amacı, kullanıcının klavye yazma alışkanlıklarını analiz ederek sürekli kimlik doğrulaması yapan ve otonom siber savunma sağlayan bir uç nokta (endpoint) güvenlik ajanı geliştirmektir. "Sıfır Güven" (Zero Trust) mimarisini benimseyen sistem, yetkisiz fiziksel erişimleri n-gram davranışsal biyometri ile tespit eder. Veri sızıntılarını 3 kademeli olay müdahale mekanizması ile engeller: sessiz istihbarat loglaması, Telegram uyarılarına sahip atlatılamaz bir 2FA bal küpü ekranı ve "Nükleer Seçenek" (ağ izolasyonu ve işletim sistemi kilidi).
